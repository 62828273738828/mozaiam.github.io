Guia rápido de comandos

Os comandos do Linux Mint mais usados nos tutoriais do canal. Abra o terminal com Ctrl + Alt + T, clique em Copiar e cole.

Sistema

Atualizar o sistema. Atualiza a lista de pacotes e os programas instalados.

$ sudo apt update && sudo apt upgrade

Limpar pacotes que sobraram. Remove pacotes que não são mais necessários.

$ sudo apt autoremove

Atualizar os programas Flatpak. Atualiza tudo o que foi instalado pelo Flatpak.

$ flatpak update

Drivers de vídeo

Ver qual é a sua placa de vídeo. Mostra o modelo da placa.

$ lspci | grep -E "VGA|3D"

Ver os drivers NVIDIA disponíveis. Mostra os drivers e qual é o recomendado.

$ ubuntu-drivers devices

Instalar o driver NVIDIA recomendado. Depois da instalação, reinicie o PC.

$ sudo ubuntu-drivers autoinstall
$ sudo reboot

Conferir o driver NVIDIA. Funciona só em placas NVIDIA, depois de reiniciar.

$ nvidia-smi

Suporte ao Vulkan em AMD e Intel. O driver já vem no sistema; este pacote completa o suporte ao Vulkan.

$ sudo apt install mesa-vulkan-drivers

Testar o Vulkan. Vale para todas as placas.

$ sudo apt install vulkan-tools
$ vulkaninfo --summary

AppImage

Dar permissão para executar. Rode na pasta onde o arquivo está. O * completa o nome da versão.

$ chmod +x pcsx2-*.AppImage

Abrir o AppImage. Também na pasta do arquivo.

$ ./pcsx2-*.AppImage

Instalar a biblioteca que o AppImage usa. Para o Linux Mint 22 ou mais novo. No Mint 21 o pacote se chama libfuse2. Não instale o pacote fuse.

$ sudo apt install libfuse2t64

Flatpak (PCSX2)

Instalar o PCSX2. Instala pelo Flathub.

$ flatpak install flathub net.pcsx2.PCSX2

Abrir o PCSX2. Abre o emulador instalado pelo Flatpak.

$ flatpak run net.pcsx2.PCSX2

Atualizar só o PCSX2. Não mexe nos outros programas.

$ flatpak update net.pcsx2.PCSX2

Ver o que está instalado. Lista os programas Flatpak.

$ flatpak list

Desinstalar o PCSX2. Remove o emulador instalado pelo Flatpak.

$ flatpak uninstall net.pcsx2.PCSX2

Informações para pedir ajuda

Dados do seu sistema. Copie o resultado e cole no comentário do vídeo. Informe também a versão do PCSX2 e o nome do jogo. O nvidia-smi só funciona em placas NVIDIA.

$ cat /etc/os-release
$ uname -r
$ lspci | grep -E "VGA|3D"
$ nvidia-smi
$ free -h
$ echo $XDG_SESSION_TYPE
