Instalar o PCSX2 no Linux Mint

Atualizado em novembro de 2026.

Testado com o PCSX2 v2.8.2 no Linux Mint 22.3 (kernel 7.0.0-42-generic)

Assista ao vídeo completo no YouTube

Antes de começar

Você vai precisar do Linux Mint, de uma BIOS extraída do seu próprio PS2 e de jogos que sejam seus. Veja como conseguir a BIOS do jeito certo no guia da BIOS.

1. Atualizar o sistema

Abra o terminal com Ctrl + Alt + T e rode:

$ sudo apt update && sudo apt upgrade

2. Conferir os drivers de vídeo

O PCSX2 depende de um bom driver de vídeo. Veja os comandos para a sua placa no guia rápido de comandos.

3. Instalar o PCSX2 com AppImage

  1. Baixe o AppImage do PCSX2 para Linux no site oficial, pcsx2.net.
  2. No terminal, entre na pasta onde salvou o arquivo (aqui, Downloads):
    $ cd ~/Downloads
  3. Dê permissão para o arquivo ser executado:
    $ chmod +x pcsx2-*.AppImage
  4. Abra o PCSX2:
    $ ./pcsx2-*.AppImage

O nome do arquivo muda a cada versão, e o * completa o nome. Se houver mais de uma versão na pasta, digite o nome completo.

Se o PCSX2 não abrir, falta a biblioteca FUSE 2 que os AppImages usam. No Linux Mint 22 ou mais novo, instale:

$ sudo apt install libfuse2t64

No Linux Mint 21, o pacote se chama libfuse2. Não instale o pacote fuse, porque ele pode causar problemas no sistema.

4. Configurar a BIOS

No PCSX2, abra Configurações > BIOS, aponte a pasta onde salvou a BIOS e atualize a lista. O passo a passo completo está no guia da BIOS.

Prefere o Flatpak?

Também funciona. Instale, abra e atualize assim:

$ flatpak install flathub net.pcsx2.PCSX2
$ flatpak run net.pcsx2.PCSX2
$ flatpak update net.pcsx2.PCSX2
